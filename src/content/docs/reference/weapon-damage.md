補強ブロックと露出した領土コアへの既定ダメージです。
**どう使うか**は[攻める](../../guide/attack/)、
**どう耐えるか**は[要塞を設計する](../../guide/fortress/)にあります。

## CBC

| 弾種 | 補強への1ヒット | 露出したコアを殴れるか |
|---|---:|---|
| 通常弾（Solid Shot） | 48 | できる |
| 徹甲弾（AP Shot） | 96 | できる |
| 榴弾（HE Shell） | 40 | できる |
| 徹甲榴弾（AP Shell） | 72 | できる |
| 迫撃砲弾 | 30 | できる |
| 破片 | 1 | できない |
| AP機関砲弾 | 3 | できない |
| 機関銃弾 | 1 | できない |
| その他ユーティリティ弾 | 1 | できない |

**機関砲と機関銃は補強を少しずつ削れますが、領土コアのHPは直接削れません。**
連射だけで壁を無視してコアを落とすことはできません。AP機関砲弾だけは、車両コアへの直撃で4ダメージを与えます。

### 炸裂弾の範囲

榴弾・徹甲榴弾・迫撃砲弾・榴散弾・対空機関砲弾は、着弾点から**半径4ブロック内の、遮られていない補強すべて**に上の表のダメージを与えます。
距離による減衰はありません。車両コアは範囲では削れず、直撃したときだけ削れます。

### 砲撃は誰の攻撃か

CBCの砲撃が誰の攻撃になるかは、発射の時点で次の順に決まります。

1. 砲を操作している人
2. 砲を設置した人（オフラインでも）
3. 砲が載っている車両の国
4. 砲が立っている領土の国

どれにも当たらない砲撃は、普通のブロックや生き物には当たりますが、補強・領土コア・車両は削りません。
自国・同盟国の砲撃は、自国・同盟国の補強と車両を削りません。
3・4の国の攻撃になる砲撃は、敵対宣言も進行中のSiegeもない国の補強・コアには効きません（[開戦の確認と敵対宣言](../../guide/siege/#開戦の確認と敵対宣言)）。

### 直撃倍率

重砲弾が**露出した領土コアそのものへ点着弾**すると、既定2.5倍が付きます。

| 状況 | 2.5倍 |
|---|---|
| 露出した領土コアへの点着弾 | 付く |
| 爆風範囲にコアが入っただけ | 付かない |
| 車両コア | 付かない |
| プレイヤー | 付かない |

## Warnautics

| 兵器 | 補強への基礎ダメージ |
|---|---:|
| 小型爆弾 | 16 |
| 対艦・海上爆弾 | 32 |
| 中型爆弾 | 40 |
| 大型爆弾 | 72 |
| MOAB | 96 |
| C4の取付面 | 64 |
| C4の周辺補強 | 8 |
| 隣接C4から露出コアへ | 最大16 |

- **C4** は敵補強への歩兵用の局所突破手段です。取付面に64、その周囲へ8。国家に所属しているなら、どちらかの国が敵対宣言している相手にしか取り付けられません
- **地雷** は対歩兵・地域拒否用で、領土コアにはダメージを与えません
- **航空爆弾** は爆心から最大12ブロックまでの露出コアへ作用します
- **巡航ミサイル** は作成・使用禁止です。補強・コア攻略手段としても無効扱いです

## 補強材料のHPと、抜くのに要る弾数

補強側の数値です。設置方法は[拠点を作る](../../guide/base/#補強する)にあります。

```rounds
title: 通常弾（48ダメージ）
damage: 48
丸石 = 32
銅インゴット = 64
鉄インゴット = 128
金インゴット = 192
ダイヤモンド = 320
```

```rounds
title: AP弾（96ダメージ）
damage: 96
丸石 = 32
銅インゴット = 64
鉄インゴット = 128
金インゴット = 192
ダイヤモンド = 320
```

```rounds
title: C4の取付面（64ダメージ）
damage: 64
丸石 = 32
銅インゴット = 64
鉄インゴット = 128
金インゴット = 192
ダイヤモンド = 320
caption: C4は個数です。ダイヤ1ブロックにつき5個要ります。
```

修理材1個で最大HPの25%が戻りますが、**被弾箇所は既定60秒修理できません。**

## 歩兵によるコア破壊工作

TNTを使う手段は別枠です。手順と条件は[攻める](../../guide/attack/#砲が届かないとき--歩兵による破壊工作)にあります。

| | |
|---|---|
| 1回のダメージ | コア最大HPの20% |
| 必要なTNT | 1回あたり4個 |
| 落とすのに必要な回数 | 無軽減で5回（TNT20個） |
