title: 兵器のダメージ
description: CBC・Warnauticsの各兵器が補強と露出コアへ与える既定ダメージ。

補強ブロックと露出した領土コアへの既定ダメージです。
**どう使うか**は[戦争をする](../../guide/siege/#外殻を抜く)、
**どう耐えるか**は[要塞を設計する](../../guide/fortress/)にあります。

## CBC

| 弾種 | 補強への1ヒット | 露出したコアを殴れるか |
|---|---:|---|
| 通常弾（Solid Shot） | 48 | できる |
| 徹甲弾（AP Shot） | 96 | できる |
| 榴弾（HE Shell） | 40 | できる |
| 徹甲榴弾（AP Shell） | 72 | できる |
| 迫撃砲弾 | 30 | できる |
| 破片 | 1 | できない |
| AP機関砲弾 | 3 | できない |
| 機関銃弾 | 1 | できない |
| その他ユーティリティ弾 | 1 | できない |

**機関砲と機関銃は補強を少しずつ削れますが、領土コアのHPは直接削れません。**
連射だけで壁を無視してコアを落とすことはできません。

### 直撃倍率

重砲弾が**露出した領土コアそのものへ点着弾**すると、既定2.5倍が付きます。

| 状況 | 2.5倍 |
|---|---|
| 露出した領土コアへの点着弾 | 付く |
| 爆風範囲にコアが入っただけ | 付かない |
| 車両コア | 付かない |
| プレイヤー | 付かない |

## Warnautics

| 兵器 | 補強への基礎ダメージ |
|---|---:|
| 小型爆弾 | 16 |
| 対艦・海上爆弾 | 32 |
| 中型爆弾 | 40 |
| 大型爆弾 | 72 |
| MOAB | 96 |
| C4の取付面 | 64 |
| C4の周辺補強 | 8 |
| 隣接C4から露出コアへ | 最大16 |

- **C4** は敵補強への歩兵用の局所突破手段です。取付面に64、その周囲へ8
- **地雷** は対歩兵・地域拒否用で、領土コアにはダメージを与えません
- **航空爆弾** は設定された範囲内の露出コアへ作用します
- **巡航ミサイル** は補強・コア攻略手段としては無効扱いです

## 補強材料のHPと、抜くのに要る弾数

補強側の数値です。設置方法は[拠点を作る](../../guide/base/#補強する)にあります。

| 材料 | 補強HP | 通常弾48 | AP弾96 | C4取付面64 |
|---|---:|---:|---:|---:|
| 丸石 | 32 | 1発 | 1発 | 1個 |
| 銅インゴット | 64 | 2発 | 1発 | 1個 |
| 鉄インゴット | 128 | 3発 | 2発 | 2個 |
| 金インゴット | 192 | 4発 | 2発 | 3個 |
| ダイヤモンド | 320 | 7発 | 4発 | 5個 |

修理材1個で最大HPの25パーセントが戻りますが、**被弾箇所は既定60秒修理できません。**

## 歩兵によるコア破壊工作

TNTを使う手段は別枠です。手順と条件は[戦争をする](../../guide/siege/#歩兵によるコア破壊工作)にあります。

| | |
|---|---|
| 1回のダメージ | コア最大HPの20% |
| 必要なTNT | 1回あたり4個 |
| 落とすのに必要な回数 | 無軽減で5回（TNT20個） |
