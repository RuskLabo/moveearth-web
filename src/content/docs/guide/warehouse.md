Warehouseはワールドに配置される敵対NPCの建造物です。
地方ごとの探索対象で、どの場所にも大量に湧く通常のモブ狩りではありません。
地図や探索で見つけたら、補給と退路を確保してから挑戦してください。

## 入る前に

建物の敷地（37×17ブロック）の外周には、力場の壁が見えます。32ブロック以内に近づくと見え始めます。
壁は目印で、何も遮りません。色で今の状態が分かります。

| 色 | 状態 |
|---|---|
| 赤 | 入ると警備隊が出動する |
| オレンジ | 戦闘中 |
| 青 | 入っても何も起きない（閉鎖時間・回収期間・クールダウン中） |

赤のときに敷地の8ブロック手前まで来ると、アクションバーに警告が出ます。

## 襲撃の流れ

1. 開放時間中に敷地の中へ入ると、**倉庫警備隊長と護衛4人**が出動します。戦わないならすぐ離れてください。
2. 隊長を倒します。**隊長のHPが半分以下になると、音とチャットでサーバー全体へ通知**され、護衛が2人増えます。
3. 隊長を倒すと、拠点内の**輸送コンテナ**が開きます。
4. 回収期間は**開放時間で10分**です。終わるとクールダウンに入り、次に挑めるのは**開放時間で8時間後**（最短2晩）です。

戦闘のルールは次のとおりです。

- 攻撃が通るのは、敷地から水平24ブロック・上下16ブロック以内にいる人の攻撃だけです。遠くからの狙撃や砲撃、撃った人が分からない砲弾・爆発は効きません。
- タレットなど機械の攻撃も効きません。
- 戦闘中に隊長が30秒見当たらないと失敗です。報酬は出ず、開放時間で5分のクールダウンに入ります。

:::danger[通知後はPvEだけではありません]
通知を見たほかのプレイヤーが現地へ来る可能性があります。
ボスを倒した人専用の個別報酬ではなく、回収するまで争奪対象です。護衛・輸送役・退路を用意してください。
:::

ボスの足元へ報酬が自動ドロップする方式ではありません。
敵の装備ドロップを報酬として探すのではなく、撃破後の輸送コンテナを確認してください。

## 戦利品

| 種類 | 内容 |
|---|---|
| 確定報酬 | 精密射撃機構2個 |
| 追加報酬 | 次の表から**いずれか1種** |

| 追加報酬候補 | 個数 |
|---|---:|
| ネザーウォート | 2〜4 |
| ネザークォーツ | 4〜8 |
| グロウストーンダスト | 3〜6 |
| ブレイズロッド | 1 |
| ガストの涙 | 1 |
| ブレイズバーナー | 1 |

精密射撃機構はスナイパー製作の専用素材です。マークスマンと同じ扱いとは限りません。
JEIの「倉庫拠点の戦利品」で報酬を、銃のレシピで必要素材を確認してください。
**バーナーは確定ではありません。** 毎周回すべてのネザー資源が出るわけでもありません。

## 建物の保護

敷地から64ブロック以内では、建築・破壊・爆発・液体・ピストンが効きません。使えるのは建物のドア・トラップドア・フェンスゲート・ボタン・レバーだけです。
敷地から128ブロック以内には領土を取れません。
自分の倉庫や国家設備として占有せず、戦闘と現地回収を楽しんでください。

開始しない、回収できない場合はクールダウン・戦闘状態・コンテナの場所を確認し、[不具合報告](../faq/#不具合を報告する)へ。
