イベントは `/event` の画面で現在の内容と順位を確認できます。
`/event status` で開催状況・自分の得点・次回までの時間、`/event top` で報酬対象の上位5名が出ます。

## 開催の流れ

開放時間の**3時間ごと**に、収穫祭と資源発見が交互に自動で始まります。
時間は開放時間で数えるので、閉鎖中は進みません。

| イベント | 長さ | 得点になる行動 |
|---|---|---|
| 収穫祭 | 30分 | 成熟した作物を収穫する |
| 資源発見 | 45分 | **指定された地方**で、**指定された鉱石**（石炭・鉄・銅のどれか）を掘る |

- 1回につき10点、収穫祭は農家、資源発見は採掘師を選んでいれば11点です。上限は2,200点です。
- 得点が入るのは、開放時間中に国家へ所属し、[放置中](../jobs/#経験値とtc)でないときだけです。
- 同点なら先にその点に達した人が上位です。

## 報酬

終了時に国家へ所属していて、**100点以上**の人が報酬の対象です。収穫祭も資源発見も同じです。

| 順位 | TC | 現物 |
|---|---|---|
| 1位 | 5TC | ダイヤモンド6、共通の報酬 |
| 2〜3位 | 4TC | ダイヤモンド3、共通の報酬 |
| 4位以下 | 2TC | 共通の報酬 |

共通の報酬はネザークォーツ4と、収穫祭なら鉄インゴット8、資源発見なら対象の鉱石に応じて石炭16・鉄インゴット8・銅インゴット12のどれかです。

- TCは終了時に自動で入ります。イベントのTCは1日10TCまでです（区切りは00:00 UTC）。
- 現物は必ず `/event claim` で受け取ります。PvP試合中は受け取れません。
- 受け取らなかった現物は、実時間で7日たつと消えます。

## 投票

投票報酬は、指定された投票サービスからサーバーへ届きます。
毎回**2TC**に加えて、次の12枠から1つが同じ確率で選ばれます。

| 枠数 | 内容 |
|---|---|
| 3 | エンドストーン8 |
| 1 | ダイヤモンドのツルハシ（効率強化V） |
| 1 | ダイヤモンドのツルハシ（修繕） |
| 1 | 追加2TC |
| 1 | 追加3TC |
| 1 | 安山岩合金6 |
| 1 | 真鍮インゴット4 |
| 1 | 電子管3 |
| 1 | 銅板6 |
| 1 | 火薬8 |

投票はこの世界でエンドストーンを入手する貴重な手段ですが、出る確率は25%です。
現物はその場で持ち物に入ります。PvP試合中なら受取待ちになり、試合後に `/event claim` で受け取ります。
