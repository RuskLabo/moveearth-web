title: Jobsと行動収入

---

`/jobs` で職業一覧・進行度・ランキングを開きます。同時に選べる職業は最大2つです。
採掘・農業・製作・戦闘など、**選んだ職業に対応する行動**が経験値になります。
外した職業の進行度は残り、再選択すると続きから育てられます。標準の上限はレベル50です。

## 経験値とTC

現在は **Job Pointとポイントショップではなく、行動に応じたTC収入** です。

| 既定の条件 | 内容 |
|---|---|
| 収入換算 | 有効な25XPにつき1TC |
| 時間上限 | 一人あたり20TC/時間 |
| 日上限 | 一人あたり80TC/日 |
| 所属 | 国家所属が必要 |
| 活動 | 放置状態ではXP・収入を得られない |

レベルアップの表示とTCの収入は別です。以前の「レベルごとに1JP」「500XPごとに追加JP」は廃止されています。
上限や不正防止の判定があるため、機械による自動処理や設置したブロックの反復破壊がそのまま収入になるわけではありません。
PvPアリーナ内の行動もJobs XPの対象外です。

## よく使う操作

| 操作 | 内容 |
|---|---|
| `/jobs` | 職業の選択・解除と進行度確認 |
| `/jobs status` | 選択職業、XP、行動収入の確認 |
| `/jobs list` | 職業一覧 |
| `/jobs join <職業>` / `/jobs leave <職業>` | 選択・解除 |
| `/jobs info <職業>` / `/jobs top <職業>` | 詳細・ランキング |
| `/balance` | 所持金、取引履歴、送金 |

収入が止まったら、職業選択・国家所属・活動状態・収入上限を確認してください。
[市場](../market/)で生産品を売る収入は、Jobsの行動収入とは別です。
