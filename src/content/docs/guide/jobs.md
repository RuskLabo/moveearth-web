title: Jobsと行動収入
description: 職業の経験値とレベルを育て、普段の行動からTCを稼ぐ。
---

`/jobs` で職業一覧・進行度・ランキングを開きます。同時に選べる職業は最大2つです。
**選んだ職業に対応する行動**だけが経験値になります。
外した職業の進行度は残り、再選択すると続きから育てられます。上限はレベル50です。

| 職業 | 経験値になる行動 |
|---|---|
| 採掘師 | 石材・ネザー岩・天然の鉱石を掘る |
| 木こり | 設置されていない原木を切る |
| 農家 | 成熟した作物を収穫する、家畜を繁殖させる |
| 狩人 | 敵対Mobを自分で倒す（スポナーやスポーンエッグのMobは除く） |
| クラフター | 装備・機械部品・高度な設備をクラフトする |
| ガンスミス | 銃・アタッチメントを作る、[銃を解体する](../gun-disassembly/) |

## 経験値とTC

経験値は行動収入（TC）にも換算されます。

| 条件 | 内容 |
|---|---|
| 収入換算 | 有効な25XPにつき1TC |
| 時間上限 | 一人あたり20TC。毎時0分にリセット |
| 日上限 | 一人あたり80TC。00:00 UTC（日本時間9:00）にリセット |
| 経験値の勢い | 1職業あたり1分に500XPまでは満額、それを超えた分は10% |
| 所属 | 国家に所属していないと、**経験値も収入も**入らない |
| 活動 | 放置中は経験値も収入も入らない |

**放置**とは、5分間、視点を動かさず、作業台・かまど・TaCZの銃作業台の完成品も取り出していない状態です。
採掘や攻撃だけでは操作に数えません。水流やピストンで体が動いても同じです。視点を動かせば再開します。

Createのデプロイヤーなど機械が行った作業、プレイヤーが設置したブロックの破壊（植えた作物の収穫は除く）、PvPアリーナ内の行動は経験値になりません。

## よく使う操作

| 操作 | 内容 |
|---|---|
| `/jobs` | 職業の選択・解除と進行度確認 |
| `/jobs status` | 選択職業、XP、行動収入の確認 |
| `/jobs list` | 職業一覧 |
| `/jobs join <職業>` / `/jobs leave <職業>` | 選択・解除 |
| `/jobs info <職業>` / `/jobs top <職業>` | 詳細・ランキング |
| `/balance` | 所持金、取引履歴、送金 |

収入が止まったら、職業選択・国家所属・活動状態・収入上限を確認してください。
[市場](../market/)で生産品を売る収入は、Jobsの行動収入とは別です。
