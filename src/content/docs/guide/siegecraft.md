[攻める](../attack/)は、**壁の前に立てている**ことを前提にしています。
このページは立てないときの話です。

守る側は壁を厚くする代わりに、**そもそも近づけなくする**ことができます。
領土を岩盤まで掘り抜いて空堀にする、というのがその極端な形です。
[Bastion](../base/#bastion領土保護)により攻撃側は敵領土内にブロックを置けないので、
橋も足場も作れません。

**これは攻略不能ではありません。** 手順が変わるだけです。

## 前進基地を建てる

最初に検討してほしいのはこれです。**自分の領土を、相手の隣に作ります。**

拠点コアを相手の領土に接するところへ置いてください。
制度上、禁止されているのは**領土の重なりだけ**で、距離の制限はありません。

置いた直後の拠点コアは**設定中**で、まだ領土ではありません。コアを補強で密閉し、密閉判定を通ると稼働します。
設定中のコアが土地を押さえておけるのは**開放時間で1時間**までで、壊して置き直しても延びません。

稼働してあなたの領土になった瞬間、

- **Bastion が今度はあなたを守ります。** 相手はそこにブロックを置けません
- あなたは**自分の領土内で自由に建てられます。** 砲台、足場、倉庫、橋の取付部
- 堀の手前まで、腰を据えて工事ができます

つまり「渡れない堀」は、**渡る準備をする場所が無い**ことで強くなっていました。
前進基地はそこを埋めます。

橋そのものは、この足場で組んでから**堀の上へ回します**（[旋回橋・跳ね橋](#旋回橋跳ね橋を架ける)）。

### 費用

| | |
|---|---|
| 拠点コアの作成 | ビーコン×1、ダイヤモンド×4、黒曜石×4 |
| 領土の広さ | 半径0〜4チャンク。**半径0なら1チャンク**で足ります |
| 維持費 | **拠点の数に応じて逓増します**（下記） |
| コアHP | 1,000 |

拠点の維持費は所持数で増えます。

| 拠点の数 | 拠点ぶんの維持費（TC） |
|---:|---:|
| 1 | 8 |
| 2 | 24 |
| 3 | 48 |
| 4 | 80 |

**4個目の前進基地は、1個目の10倍払うことになります。** 前線を増やすほど重くなるので、
包囲は「同時にいくつ持つか」を含めた判断になります。

### 相手にできること

**前進基地は殴れます。** HP1,000のコアが相手の目の前にあるので、
相手はそこを攻めることができます。国家が攻撃側なら**占領されます。**

つまりこれは一方的な手ではありません。**あなたが腰を据えた分、相手にも的ができます。**
守っていた側が、いつの間にか攻める側になることがあります。

:::tip[掘って待つ側が損をします]
堀を掘って籠城していると、**その時間で相手の城が目の前に建ちます。**
待つほど相手の準備が整うので、「掘り終わったから安全」にはなりません。
:::

## 渡る手段

前進基地から先、堀そのものを越える方法です。

| 手段 | 届く距離 | 備考 |
|---|---:|---|
| 坑道を掘る | 無制限 | 無料だが遅い。底まで降り、横に掘り、登り返す |
| 加重イジェクタで飛び込む | 32ブロック | 安い。着地した者は孤立する |
| 旋回橋・跳ね橋 | 橋桁の長さ | 部隊を渡せる。自分の側で組んでから回す |
| ボート・Sableの船 | 無制限 | 水のある堀・川だけ。自分の側で浮かべてから漕ぎ出す |
| 飛行体 | 無制限 | 物資も運べる。最も高い |

**掘り抜かれた堀の幅で、要る装備が決まります。** 先に見に行ってください。

:::caution[メカニカルピストンでは架けられません]
ピストンは、押し出すブロックの通り道が**自国以外の領土**（同盟国を含む）に1マスでも入ると、組み立てを拒みます。
補強されたブロックや領土コアも押せません。デプロイヤーも他国の領土にはブロックを置けません。
:::

### 旋回橋・跳ね橋を架ける

Bastion が止める機械はピストンだけです。Sable の可動体（Create: Simulated のスイベルベアリング、
Absolute Kinematics のヒンジ、フィジックスアセンブラーで組んだもの）や、
Create のメカニカルベアリング・ガントリー・ロープ滑車が敵領土の上へ入ることは止めません。

1. 前進基地の岸に軸を置きます。水平に回すならスイベルベアリングを上向きに、跳ね上げ式ならヒンジを使います
2. 橋桁を**自分の領土か誰の土地でもない場所**で組み、軸につなぎます。超接着剤は他国の領土に掛かる範囲に使えないので、桁は岸に沿って寝かせる（跳ね橋なら立てる）形で組みます
3. 組み立てて回転動力を入れ、桁を堀の上へ回します

| 限界 | |
|---|---|
| 長さ | 桁は自分の側に寝かせて組むので、岸に沿って取れる長さまで |
| ヒンジの角度 | ±90度まで |
| 引っかかったとき | 桁が壁などに当たると止まり、押し続けても力は溜まりません。外れても跳ね回りません |
| 守り | 桁の補強は、[車両コア](../../reference/vehicle-core/)を載せるまで効きません。相手の砲で崩されます |

:::note[坑道は塞がれていません]
Bastion が禁じているのは**設置**であって、**採掘ではありません。**
堀の底まで降りて向かいの壁を掘り、登り返せば中に入れます。

岩盤まで掘られていても、**向かいの壁は残っています。** そこを掘ってください。
ただし他国の領土で未補強のブロックを掘ると、その国に通知が届きます（掘った人ごとに5分に1回、前回からの個数つき）。
:::

## 時計は止まっています

**攻撃側の誰かが相手の領土内にいて手を動かしている間、ローリングSiegeの残り時間は減りません。**
累計45分までです。

これは包囲において一番大事なルールかもしれません。

- **堀の底で掘っている間、時計は止まっています**
- 急いで雑に渡るより、**きちんと橋を架けたほうが結果的に速い**ことがあります
- 掘っている間に戦争が終わる、ということはありません

数えるのは**ブロックを壊す・殴る・殴られる**の3動作で、直近2分以内が条件です。デプロイヤーなど機械の動作は数えません。
坑道を掘り続けているなら常に満たしますが、**止まると数分で時計が動き出します。**
1人を置いて放置する、という使い方はできません。

予算も有限です。45分を使い切ると時計が動き出すので、
**そこまでに実際にダメージを通す**必要があります。

## 順番

1. **見に行く。** 堀の幅と深さ、領土の境界がどこか
2. **前進基地を置く。** 相手の境界に接するところへ。半径0で十分
3. **自分の領土で組み立てる。** 橋、砲台、足場
4. **渡る。** この時点で時計は止まっています
5. **壁を抜く。** ここから先は[攻める](../attack/)の話です
