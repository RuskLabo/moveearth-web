[攻める](../attack/)は、**壁の前に立てている**ことを前提にしています。
このページは立てないときの話です。

守る側は壁を厚くする代わりに、**そもそも近づけなくする**ことができます。
territory を岩盤まで掘り抜いて空堀にする、というのがその極端な形です。
[Bastion](../base/#bastion領土保護)により攻撃側は敵領土内にブロックを置けないので、
橋も足場も作れません。

**これは攻略不能ではありません。** 手順が変わるだけです。

## 前進基地を建てる

最初に検討してほしいのはこれです。**自分の領土を、相手の隣に作ります。**

拠点コアを相手の territory に接するところへ置いてください。
制度上、禁止されているのは**領土の重なりだけ**で、距離の制限はありません。

そこがあなたの領土になった瞬間、

- **Bastion が今度はあなたを守ります。** 相手はそこにブロックを置けません
- あなたは**自分の領土内で自由に建てられます。** 砲台、足場、倉庫、橋の取付部
- 堀の手前まで、腰を据えて工事ができます

つまり「渡れない堀」は、**渡る準備をする場所が無い**ことで強くなっていました。
前進基地はそこを埋めます。

橋そのものは、この足場から**機械で押し出します**。堀の上に1個ずつ置くわけではないので、
Bastion には触れません。

### 費用

| | |
|---|---|
| 拠点コアの作成 | ビーコン×1、ダイヤモンド×4、黒曜石×4 |
| 領土の広さ | 半径0〜4チャンク。**半径0なら1チャンク**で足ります |
| 維持費 | **拠点の数に応じて逓増します**（下記） |
| コアHP | 1,000 |

拠点の維持費は所持数で増えます。

| 拠点の数 | 拠点ぶんの維持費 |
|---:|---:|
| 1 | 8 |
| 2 | 24 |
| 3 | 48 |
| 4 | 80 |

**4個目の前進基地は、1個目の10倍払うことになります。** 前線を増やすほど重くなるので、
包囲は「同時にいくつ持つか」を含めた判断になります。

### 相手にできること

**前進基地は殴れます。** HP1,000のコアが相手の目の前にあるので、
相手はそこを攻めることができます。国家が攻撃側なら**占領されます。**

つまりこれは一方的な手ではありません。**あなたが腰を据えた分、相手にも的ができます。**
守っていた側が、いつの間にか攻める側になることがあります。

:::tip[掘って待つ側が損をします]
堀を掘って籠城していると、**その時間で相手の城が目の前に建ちます。**
待つほど相手の準備が整うので、「掘り終わったから安全」にはなりません。
:::

## 渡る手段

前進基地から先、堀そのものを越える方法です。

| 手段 | 届く距離 | 備考 |
|---|---:|---|
| 坑道を掘る | 無制限 | 無料だが遅い。底まで降り、横に掘り、登り返す |
| 加重イジェクタで飛び込む | 32ブロック | 安い。着地した者は孤立する |
| メカニカルピストンで橋を架ける | 64ブロック | 部隊を渡せる。自分の領土に据えれば Bastion に触れない |
| 飛行体 | 無制限 | 物資も運べる。最も高い |

**掘り抜かれた堀の幅で、要る装備が決まります。** 先に見に行ってください。

堀の幅が64を超えているなら、飛行体以外の選択肢は坑道だけになります。

:::note[坑道は塞がれていません]
Bastion が禁じているのは**設置**であって、**採掘ではありません。**
堀の底まで降りて向かいの壁を掘り、登り返せば中に入れます。

岩盤まで掘られていても、**向かいの壁は残っています。** そこを掘ってください。
:::

## 時計は止まっています

**攻撃側の誰かが相手の領土内にいて手を動かしている間、ローリングSiegeの残り時間は減りません。**
累計4開放時間ぶんまでです。

これは包囲において一番大事なルールかもしれません。

- **堀の底で掘っている間、時計は止まっています**
- 急いで雑に渡るより、**きちんと橋を架けたほうが結果的に速い**ことがあります
- 掘っている間に戦争が終わる、ということはありません

数えるのは**ブロックを壊す・殴る・殴られる**で、直近2分以内が条件です。
坑道を掘り続けているなら常に満たしますが、**止まると数分で時計が動き出します。**
1人を置いて放置する、という使い方はできません。

予算も有限です。4開放時間を使い切ると時計が戻るので、
**そこまでに実際にダメージを通す**必要があります。

## 順番

1. **見に行く。** 堀の幅と深さ、territory の境界がどこか
2. **前進基地を置く。** 相手の境界に接するところへ。半径0で十分
3. **自分の領土で組み立てる。** 橋、砲台、足場
4. **渡る。** この時点で時計は止まっています
5. **壁を抜く。** ここから先は[攻める](../attack/)の話です
