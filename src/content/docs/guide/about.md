MoveEarthは、工場で物資を作り、車両や飛行船で運び、国家を作って土地を守るMinecraft Java Editionサーバーです。
工業だけ、戦闘だけではなく、**生産・物流・外交・防衛がつながること**を目指しています。

| 基本環境 | 内容 |
|---|---|
| Minecraft | Java Edition 1.21.1・NeoForge |
| サーバー開放時間 | 毎日19:00〜23:00・日本時間（JST） |
| 導入 | 公式MoveEarth Modpack。接続前に指定された版へ更新 |
| ガイドの対象 | Season 2・v3.2 |
| 経済 | 独自通貨TC（Trade Credit）。金貨アイテムや外部銀行MODは不要 |

Createを工業の入口に、CEE（Create Electro Energetics）の電力、Mekanismの化学・原子力へ進みます。
Create Big Cannons・Warnautics・TaCZで戦い、Sable・Aeronauticsの移動体で重火力や荷物を運べます。

## 最初から知っておきたいこと

- 国家に所属すると収納・Jobs収入などが利用できるようになります。ただし収納は場所や権限の制限もあります。
- ネザーとエンドへ行く通常の攻略は前提にしていません。特殊資源は[倉庫襲撃](../warehouse/)など別の入手経路を探してください。
- Y0以下には酸素の危険があります。[生活と探索](../survival/)を先に確認してください。
- 物資の市場は遠隔倉庫ではありません。[現物の受け渡しは現地](../market/)です。
- 戦闘中に手動ログアウトすると死亡します。[戦闘ルール](../combat/)を確認してください。

[参加方法](../../join/)から導入し、ゲーム内ではまず **Nキー** で国家ハブを開いてください。
