MoveEarthは、工場で物資を作り、車両や飛行船で運び、国家を作って土地を守るMinecraft Java Editionサーバーです。
工業だけ、戦闘だけではなく、**生産・物流・外交・防衛がつながること**を目指しています。

| 基本環境 | 内容 |
|---|---|
| Minecraft | Java Edition 1.21.1・NeoForge |
| プレイできる時間 | 毎日19:00〜23:00・日本時間（JST） |
| 導入 | 公式MoveEarth Modpack。**MoveEarth 3.3が必要**（Season 2版）。古い版はログイン時に拒否されます |
| ガイドの対象 | Season 2 |
| 経済 | 独自通貨TC（Trade Credit）。金貨アイテムや外部銀行MODは不要 |

Createを工業の入口に、CEE（Create Electro Energetics）の電力、Mekanismの化学・原子力へ進みます。
Create Big Cannons・Warnautics・TaCZで戦い、Sable・Aeronauticsの移動体で重火力や荷物を運べます。

## 最初から知っておきたいこと

- 国家に所属すると、チェストなどの収納やJobs収入を利用できるようになります（収納を使えるのは自国の領土と自国の車両の上です）。
- ネザーやエンドへ行く通常の攻略とは異なり、特殊資源は[ネザー資源](../nether/)や[倉庫襲撃](../warehouse/)など別の入手経路が用意されています。
- Y0以下の地下には酸素の危険があります。探索前に[生活と探索](../survival/)を確認してください。
- 物資の市場は開始時から使えます。遠隔倉庫ではなく、[現物の受け渡しを現地で行う仕様](../market/)です。
- 戦闘中に手動ログアウトすると即死扱いになります。詳細は[戦闘ルール](../combat/)をご確認ください。

[参加方法](../../join/)から導入し、ゲーム内ではまず **Nキー** で国家ハブを開いてください。
