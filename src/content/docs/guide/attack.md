title: 攻める
description: 外殻の抜き方、直撃倍率の活かし方、破壊工作。効率よく落とすための実践。
---

**ルールは[戦争をする](../siege/)にあります。このページは実践です。**
どう使えば早く落ちるか、どこで無駄が出るかを扱います。

攻撃側に時間制限はありません。あるのは**手を止めないこと**だけです。
だから効率とは、**同じ時間でどれだけ多く壁を削れるか**に尽きます。

## 何を使うか

| 手段 | 向いている場面 | 注意 |
|---|---|---|
| **CBCの重砲** | 主力。壁を抜き、露出コアへ直撃させる | 機関砲・機関銃はコアを削れない |
| **Warnautics C4** | 歩兵による局所突破。取付面に64 | 壁まで歩いて取り付ける必要がある |
| **Warnautics 航空爆弾** | 範囲攻撃。MOABで96 | 巡航ミサイルは補強・コアに無効 |
| **採掘** | 静かで確実。弾薬が要らない | 補強HPを削り切るまで壊せない。時間が掛かる |

数値は[兵器のダメージ](../../reference/weapon-damage/)にまとめてあります。

:::caution[機関砲でコアは落ちません]
機関砲と機関銃は補強を少しずつ削れますが、**領土コアのHPは削れません。**
どれだけ撃ち込んでも、壁を無視してコアを落とすことはできません。
:::

## 外殻を抜く

### 一点に集中する

**被弾した位置は、防衛側が60秒間修理できません。** 再被弾するたびに延長されます。
つまり同じ箇所を撃ち続けている限り、そこは絶対に直りません。

```voxel
title: 集中 ― 1箇所を撃ち続ける
legend:
  # = 無傷の補強 #4e5a48
  x = 削れた補強 #7a5a3a
  ! = 抜けた #e05a5a
layers:
---
#######
---
###!###
---
###!###
---
###x###
---
#######
caption: 撃ち続けているあいだ、この列は修理されません。貫通すれば中へ進めます。
```

```voxel
title: 分散 ― 広く浅く削る
legend:
  # = 無傷の補強 #4e5a48
  x = 削れた補強 #7a5a3a
layers:
---
#x###x#
---
##x#x##
---
x###x##
---
##x##x#
---
#x###x#
caption: どこも貫通していません。60秒ごとに、撃っていない場所から順に直されます。
```

**削った総量が同じでも、通るかどうかが変わります。** 攻撃側の効率は集中で決まります。

### 壁は1枚ずつしか抜けない

補強された壁が残っているあいだ、その背後のコアへ爆発ダメージは通りません。
砲弾はまず当たった補強を削り、**射線または爆発経路が開いてから**内部へ届きます。

[要塞を設計する](../fortress/)側はこれを利用して殻を重ねてきます。

```voxel
title: 外殻を1枚抜いた直後 ― コアはまだ露出していない
legend:
  = = 地面 #2f3a2a
  # = 補強ブロック #4e5a48
  C = 領土コア #9bc86a
  ! = 抜いた穴 #e05a5a
layers:
---
===============
---
.#...#...#####.
---
.!...#...#.C.#.
---
.#...#...#####.
---
.#...#.........
---
.#.............
caption: 左端の外殻を抜いたところ。中央の殻と、閉鎖されたコア室が残っています。この時点ではコアへ1ダメージも通りません。
```

**手前の1枚を抜いた時点では、まだ何も起きていません。**
殻の数だけ同じ作業を繰り返す必要があり、最後の1枚を抜いて初めてコアが露出します。

:::note[壊して置き直しても補強は消えません]
CBCの爆発でブロックが変換されたり丸石化したりしても、古い補強データは新しいブロックへ引き継がれます。
「壊して置き直させれば無補強になる」ということは起きません。
:::

### 採掘という選択肢

補強ブロックは通常の採掘では即座に壊れません。**採掘の試行は補強HPへ処理されます。**
削り切ってから、ようやく通常のブロックとして壊せます。

弾薬も砲も要らないので、**守りが薄い時間帯や、砲を持ち込めない場所では現実的な手段**です。
ただし敵領土内で足場や遮蔽を作ることは[Bastion](../base/#bastion領土保護)が禁じています。

### 何発掛かるか

補強材料によって必要な発数が変わります。**壁の材質を見てから弾種を決めてください。**

```rounds
title: 通常弾（48ダメージ）
damage: 48
丸石 = 32
銅 = 64
鉄 = 128
金 = 192
ダイヤモンド = 320
```

```rounds
title: AP弾（96ダメージ）
damage: 96
丸石 = 32
銅 = 64
鉄 = 128
金 = 192
ダイヤモンド = 320
caption: AP弾はダイヤを4発で抜けます。通常弾なら7発なので、硬い壁ほどAP弾の差が開きます。
```

**通常弾7発とAP弾4発の差は、硬い材料でだけ出ます。** 丸石相手はどちらも1発なので、
薄い外殻に高い弾を使うのは無駄です。**外殻は安い弾で、内殻はAP弾で**が基本になります。

殻が3枚あれば、単純にこの3倍です。

## 直撃2.5倍を取る

**露出した領土コアそのものへ点着弾させると、既定2.5倍が付きます。**

| 当て方 | 2.5倍 |
|---|---|
| 露出コアへの直撃 | **付く** |
| 爆風範囲にコアが入っただけ | 付かない |
| 車両コア・プレイヤー | 付かない |

外殻を開けたあと、**爆風で「だいたい当てる」のと直撃させるのとで2.5倍の差**が出ます。
だから壁を開けた次にやるべきは、**コアへ真っ直ぐ通る射線を作ること**です。

固定砲では角度が取れないなら[車両コア](../../reference/vehicle-core/)で砲を運びます。
車両の価値は装甲ではなく、**この射線を作れること**にあります。

## 歩兵によるコア破壊工作

重砲をコア室まで運べないときの手段です。既定で有効。
**要るのは溶接機とTNT20個、約5分の時間、そのあいだ立っていられる安全です。**

### 手順

1. 敵の領土コアを `EXPOSED` にする
2. メインハンドに**溶接機**、オフハンドに**TNTを4個以上**持つ
3. コアから4ブロック以内で、コアを見ながらスニーク右クリック
4. その場で**20秒**、視線・姿勢・道具を維持する
5. TNTを4個消費し、**40秒の信管**が作動する

### 途中で中止になる条件

設置の20秒間に次のどれかが起きると中止されます。**完了するまでTNTは消費しません。**

- 0.5ブロックを超えて動く
- 被弾する
- コアから視線を外す、道具を持ち替える
- ダウン・拘束される
- ログアウトする

### 数えておくこと

| | |
|---|---|
| 1回のダメージ | コア最大HPの20% |
| 落とすのに必要な回数 | 無軽減でも5回（TNT20個、約5分） |
| 同時進行 | 1コアにつき1件、攻撃者1人につき1件 |
| 作動中の警告 | 周囲32ブロックにBossbarと毎秒の警告音 |

:::caution[サーバー再起動をまたぎません]
設置済みの工作は保存されません。開放時間の終わりをまたぐ計画は立てないでください。
:::

### 解除されます

所有国・同盟国のプレイヤーが**溶接機でコアをスニーク右クリックし、5秒維持**すると解除されます。

ただし解除担当者が被弾・移動・ダウンで条件を失うと進捗はリセットされます。
**工作を仕掛けたら、解除に来る相手を撃つ役を別に用意してください。** 仕掛けるだけでは通りません。

## よくある失敗

| 失敗 | 何が起きるか |
|---|---|
| 初動ロックの5分を無駄にする | 相手は回復しながら準備でき、こちらには60分のクールダウンが付く |
| 手を止めて30分 | それまでの戦果に関わらず終了。時間制限ではなく**途切れ**が敵 |
| 壁を広く浅く削る | 撃っていない場所から直される。60秒の修復待ちは位置ごと |
| 機関砲でコアを狙う | 補強は削れるがコアHPは減らない |
| コアを爆風で狙う | 2.5倍が付かない。直撃させれば2.5倍 |
| 外殻を1枚抜いて満足する | 殻が複数あればまだ何も起きていない |
| コアHP0で引き上げる | **そこから30分守り切らないと奪還される**。落としてからが本番 |
| 落とした車両を放置する | 修理されると[貨物回収権が消えます](../../reference/vehicle-core/#hpが0になったら) |
| 工作を開放時間の終わりにまたがせる | 設置済みの工作は保存されない |
