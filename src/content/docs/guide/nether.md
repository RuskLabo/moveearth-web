MoveEarthでは通常のネザーポータルに入れません。
ネザー系の資源は[地方の資源の偏り](../resources/)とは関係なく、次の方法で手に入れます。

## 入手先の一覧

| 資源 | 主な入手先 |
|---|---|
| ブレイズロッド | ゲート生成器とブレイズロッド精製装置で自国生産（このページ） |
| ネザーシャード | ゲート生成器の戦闘で入手。精製装置の材料専用 |
| ネザーウォート、クォーツ、グロウストーンダスト、ブレイズロッド、ガストの涙、ブレイズバーナー | [倉庫襲撃](../warehouse/)の報酬の抽選枠（1回の報酬でどれか1種類） |

ブレイズロッドを安定して手に入れるには、次の流れで自国生産します。

1. **ゲート生成器**を動かし、現れる敵を倒して**ネザーシャード**を手に入れる
2. **ブレイズロッド精製装置**で、棒とネザーシャードからブレイズロッドを作る

## ゲート生成器

回転動力でゲートを充填し、開いたゲートから出てくる敵を倒すとネザーシャードが手に入る設備です。

| 項目 | 内容 |
|---|---|
| クラフト | 黒曜石4、精密機械2、真鍮ケーシング2、火打石と打ち金1 |
| 置ける場所 | 自国の領土内だけ |
| 止まるとき | 自国が関わるSiegeの間（攻撃側でも）と、陥落後その決着がつくまで |
| 動力 | **128 RPM以上**、1 RPMあたり64 SU |
| 充填時間 | 256 RPMで5分、128 RPMで10分 |

充填は少しずつ保存されるので、サーバーの再起動やチャンクの読み込み解除で失われることはありません。

### 開門と戦闘

充填が終わったあと、自国のメンバーが生成器から16ブロック以内に近づくとゲートが開きます。
ただし、次のときは充填済みのまま待ちます。待っている理由は、近くにいるメンバーに最大30秒ごとに表示されます。

- 自国のゲート戦闘がすでに1件進んでいる
- サーバー全体でゲート戦闘が4件進んでいる
- 水平96ブロック以内で、どこかの国のゲート戦闘が進んでいる

開いたら、**5分以内に3波の敵をすべて倒す**と成功です。前の波を倒し切ると次の波が来ます。

| 波 | 敵 |
|---|---|
| 1 | ウィザースケルトン3、ブレイズ2 |
| 2 | ブレイズ3、ピグリンブルート2 |
| 3 | ウィザースケルトン3、ブレイズ3、ピグリンブルート2 |

- 敵の体力は通常の2倍、近接攻撃のダメージは1.5倍です。
- 敵は**プレイヤーの攻撃でしかダメージを受けません。** 機械やトラップ、タレットでは倒せません。
- 敵はアイテムを落とさず、火をつけたりブロックを壊したりもしません。
- 生成器から24ブロック以上離れた敵は引き戻されます。

成功すると、生成器の上に**ネザーシャードが4個**落ちます。

### 失敗になる場合

次の場合は戦闘が終わり、報酬はありません。生成器は残るので、もう一度充填できます。

- 5分の制限時間が切れた
- 戦闘中に自国がSiegeに関わった（攻撃側でも）、または生成器の場所が自国の領土でなくなった
- 生成器から32ブロック以内に誰もいない状態が30秒続いた
- 敵を呼び出せる場所がなかった

### 開かないとき

エンジニアゴーグルで生成器を見ると、今の状態が出ます。

| 表示 | 原因 |
|---|---|
| 128 RPM以上で回す必要があります | 回転が足りない |
| 停止中（自国領外、またはSiege中） | 上の「止まるとき」に当たる |
| チャージ完了 ・ 自国民が近づくと開門 | 16ブロック以内に自国のメンバーがいない |
| チャージ完了・他のゲート戦闘の終了待ち | 戦闘数の上限か、96ブロック以内の別の戦闘 |

## ブレイズロッド精製装置

ネザーシャードを使って、棒をブレイズロッドに変える装置です。メカニカルプレスと同じように上下に動いて加工します。

| 項目 | 内容 |
|---|---|
| クラフト | 真鍮板4、シャフト1、精密機械2、メカニカルプレス1、高炉1 |
| 材料 | 棒1 ＋ ネザーシャード1 → ブレイズロッド1 |
| 動力 | 装置を横に貫く軸から入れる。**48 RPM以上**、1 RPMあたり64 SU |
| 加熱 | **溶岩を通したファンの風**が装置に届いていること |
| 加工時間 | 1本あたり、256 RPMで3分、48 RPMで16分 |

回転を上げると速く作れますが、そのぶん応力も増えます。1本あたりに使う「応力 × 時間」はどの速度でも同じなので、生産量を増やすには装置の台数と動力を増やすことになります。

### 自動化

- **ベルトやデポの上に置く**と、その場で加工します。下を通る棒とネザーシャードを各2個まで取り込み、できたブレイズロッドをベルトに戻します。1本のベルトの上に何台も並べると、材料を分け合って並行に加工します。
- 側面につないだベルト、ファンネル、シュートからも材料を入れられます。

ゲート生成器と精製装置の仕組み、サーバーの実際の数値は、JEIでブレイズロッドやネザーシャードのレシピを開くと確認できます。
