## 気温を確認する

Cold Sweat連携の左上HUDで現在温度と危険状態を確認できます。
快適なときは控えめな表示、極寒・高温では装備や熱源への案内が出ます。
表示された温度だけで判断せず、状態と推奨行動も確認してください。防寒装備や適切な熱源を用意して遠征します。

閉鎖時間中は昼夜が止まるため、季節はプレイできる時間の分だけゆっくり進みます。

## Y0以下はガスマスクが必要

:::danger[通常の採掘と同じ感覚で深く掘らないでください]
Y0以下では酸素が薄く、ガスマスクとフィルターなしでは**5秒で酸素が尽き**、そのあと毎秒、**最大HPの15%に当たるダメージ**を受けます。約12秒で死亡します。
酸素の警告が出たらすぐ上へ戻り、ガスマスクを装備してから再開してください。
:::

Y0以下では松明を置けません（置こうとした松明は消えて、1個減ります）。

マスクだけでなく**フィルター残量**を確認します。活性炭フィルター1個は、静止していれば180秒もちます。
次の条件では消耗が速くなり、重なると掛け算になります。予備を持参してください。

| 条件 | 消耗 |
|---|---|
| Y-32以下 | 2倍 |
| ダッシュ | 1.5倍 |
| 採掘中 | 2倍 |
| 戦闘中（攻撃・被弾） | 2.5倍 |

| 作業台レシピ | 材料 |
|---|---|
| ガスマスク | 革1、板ガラス2、鉄インゴット1、銅インゴット2、活性炭フィルター1 |
| 活性炭フィルター（2個できる） | 木炭1、紙1、銅インゴット1、羊毛1（並べ方は自由） |

残量はアイテムの説明やHUDで確認できます。

## ベッド・焚き火で休む

戦闘から離れ、ベッドで休むか、火のついた通常の焚き火の近くで静止するとHPを回復できます。
移動・攻撃・被弾・ダウンなどで休息は中断されます。

| 既定の設定 | 内容 |
|---|---|
| 共通の回復予算 | 一人あたり、開放時間30分ごとに最大20HP |
| ベッド | 5秒の準備後、2秒ごとに1HP |
| 焚き火 | 半径4ブロック以内、4秒ごとに1HP |

ベッドと焚き火で別々に20HP使えるわけではありません。魂の焚き火では回復しません。

## 死亡とリスポーン

ベッドで寝ると、その場所がリスポーン地点になります。**自国の領土内にベッドを置けば、仲間の近くから再開できます。**

ベッドが無いと、死ぬたびに遠くのランダムな地点へ戻されます。

- 出現地点は、自国・同盟国以外のプレイヤーから**384ブロック以上**、前回のランダム出現地点から**768ブロック以上**離れた場所です。自国・同盟国以外の領土には出ません。
- 見つからないときは条件を緩め、他国プレイヤーから192ブロック以上の場所を選びます。それも無ければ10秒後に探し直します。
- 探しているあいだはダメージを受けません。出現後の10秒間は、ダメージと炎を受けません。

## 地図と移動

公式パックのMap Atlasesと地図上の領土表示を使い、国家の位置を確認できます。
領土表示の切替キーは初期状態では未割当なので、キー設定で割り当ててください。
市場の目的地は[ウェイポイント](../market/#目的地取消受取)で表示できます。

TPAは廃止されています。通常の移動・車両・飛行船による移動を前提に計画してください。
Map Atlases以外の地図・ミニマップMODを入れると、ゲームが起動しません。ほかのクライアント補助MODは、導入前に[参加案内](../../join/)をご確認ください。

## 特殊資源

ネザー・エンドに行く通常の入手法は使えません。
資源は8つの地方ごとに偏在しています。詳細は[地方と資源](../resources/)を確認してください。ブレイズロッドは自国領内の設備で生産できます。詳細は[ネザー資源](../nether/)を確認してください。
ブレイズバーナーなど一部のネザー由来の品は[倉庫襲撃](../warehouse/)、エンドストーンは[投票報酬](../events/)で入手できます。
