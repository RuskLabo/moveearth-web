拠点の中心は**領土コア**です。コアが守られている限り土地は自分のもので、
コアが露出すれば戦争の標的になります。

このページは**補強を覚える → それで密閉を作る → 払い続ける**の順に進みます。
補強はブロックを硬くする作業、密閉はそれでコアを完全に囲うことで、**守りの本体は後者です。**

## 領土コア

領土は国家のコアを中心に成立します。

| コア | 既定最大HP | 入手方法 | 落とされたら |
|---|---:|---|---|
| 首都コア | 2,000 | 国家設立時にサーバーが自動設置 | 国は残る。陥落するたびに領土半径が2縮む（4→2→0） |
| 拠点コア | 1,000 | 作業台でクラフト（ビーコン×1、ダイヤ×4、黒曜石×4） | 攻撃側が国家なら占領され、無所属プレイヤーの場合や領土が競合した場合は中立化する |
| 車両コア | 600 | 作業台でクラフト（オブザーバー×1、ダイヤ×2、鉄ブロック×2、銅ブロック×4） | Sable移動体の所有・補強・HP・維持費を管理する |

置いた直後の拠点コアは**設定中**で、まだ領土ではありません（Bastion も効きません）。
密閉判定を通ると稼働します。設定中のコアが土地を押さえておけるのは**開放時間で1時間**までで、壊して置き直しても延びません。
1時間を過ぎると他国が割り込めるようになりますが、**他国に取られていない範囲は引き続き補強でき**、密閉して稼働まで進められます。
予約の残り時間は、コアの画面と溶接機を構えたときの表示で確認できます。

コアは**補強された密閉構造の中に置いて初めて**防御力を発揮します。
厚い壁に埋めるだけでは足りません。ドア、床、天井、整備経路まで含めて密閉してください。

## 補強する

補強を行うには**補強用溶接機**が必要です。溶接機は作業台でクラフトできます（鉄インゴット×2、銅インゴット×1、棒×2）。

溶接機をメインハンドに、補強材料をオフハンドに持って対象ブロックを右クリックします。

| 材料 | 補強最大HP |
|---|---:|
| 丸石 | 32 |
| 銅インゴット | 64 |
| 鉄インゴット | 128 |
| 金インゴット | 192 |
| ダイヤモンド | 320 |

- 修理には補強した素材と同じ材料（鉄補強なら鉄インゴット）を消費します。材料1個あたり戻るのは**最大HPの25%**。
- 新規補強は即時完成しません。**30秒の起動待ち**のあと、**60秒かけて**HPが増えます。起動待ちの補強は密閉に数えません
- 施工・起動中は見た目、オーバーレイ、進捗表示、周囲に聞こえる作業音で確認できます
- Jade導入環境（ブロック情報を表示するHUD MOD）では補強の有無・状態・HPを見られます
- 溶接機の範囲施工は 1×1 / 3×3 / 5×5 で、選択範囲の外周が緑色で表示されます（溶接機を持ってマウスホイール回転で切替）

### 自国の補強を外す

権限を持つメンバーは、**溶接機でスニーク右クリック**すると、下のブロックを壊さずに自国の補強だけを外せます。
範囲は施工と同じ1×1 / 3×3 / 5×5です。溶接機の耐久を消費し、材料の払い戻しはありません。
被弾した位置の修復待ちは、補強を外しても消えません。密閉防壁を外すとコアが露出するので、施工場所を確認してください。
自国・同盟国の補強は、つるはしで掘っても削れません。外すときはこの撤去機能を使います。

補強済みのブロックをCreateのレンチ等で回収・回転させる操作も制限されます。敵領土ではBastionが粘着剤やメカニカルピストンによる保護回避を防ぎます。

:::caution[被弾した場所はすぐに直せません]
有効ダメージを受けた位置は既定**60秒の修復待ち**になります。再被弾で延長され、
**補強を壊して同じ位置にブロックを置き直しても回避できません。**
修復待ちが明けてから修理可能になり、新規補強を行う場合はさらに通常の30秒起動待ちとHP増加が必要です。
建設中の補強が被弾すると自動のHP増加は止まり、以後は手動修理になります。
:::

## 密閉が成立している状態

補強しただけでは守りになりません。**その補強で、コアを隙間なく囲って初めて**守りが成立します。

コアが完全に囲まれていると、領土コアの状態は**密閉**のままです。

## 露出している状態

囲いに1ブロックでも穴があると、コアは**露出**へ移り、**コアへ直接ダメージが通ります。**
補強の厚さは関係ありません。

横を固めても、上から掘られれば同じことです。密閉判定は**立体**で見ます。
:::

### 何が遮蔽として数えられるか

| 数えられる | 数えられない |
|---|---|
| 有効な補強が付いた、十分な衝突判定を持つブロック | 未補強のブロック |
| 補強されたドア（**開いていても**遮蔽として扱われます） | 破壊された補強 |
| 補強されたトラップドア | 停止中の補強（維持費の長期未払いなど） |

溶接機のオーバーレイは補強状態だけでなく、**露出の原因となる隙間や未補強部分**を見つけるのにも使えます。
**露出**になっているのに原因が分からないときは、まずこれで一周してください。

## Bastion領土保護

他国領土では、権限を持たないプレイヤーの次の行動が抑止されます。

- 通常ブロック・液体の設置
- ボート・トロッコなどの設置
- エンダーパールによる侵入
- Createの粘着剤・メカニカルピストンによる領土保護の迂回

敵領土でも降車・降下はできます。降下兵にも設置とパールの制限は掛かりますが、
**C4と露出コアへの工作は通常どおり**使えます。降車を理由にした強制帰還はありません。

自国・同盟国であっても**領土・同盟領土アクセス**権限が必要です。同盟国の領土では、さらに相手国からの建築の許可が要ります（下記）。
C4を相手の補強面や露出コアへ取り付ける操作は例外として許可されます。ただし国家に所属しているなら、
どちらかの国が[敵対宣言](../siege/#開戦の確認と敵対宣言)している相手に限ります。

未補強のブロックは他国の人でも掘れますが、掘られると国家に通知が届きます（掘った人ごとに5分に1回、前回からの個数つき）。

:::danger[維持費を止めるとBastionも止まります]
維持費が長期未払いでBastionが停止している領土では、この保護は働きません。
:::

### 同盟国の権限

同盟国のメンバーは、許可しない限り自国の領土で建築・収納・補強ができません。
外交管理の権限を持つメンバーが、同盟国ごと、またはそのメンバー個人ごとに許可します。

| 権限 | できること | 同盟国側で要る役職権限 |
|---|---|---|
| 建築 | ブロックの設置・破壊 | 領土・同盟領土アクセス |
| 保管庫 | 収納の使用 | なし |
| 補強 | 補強の施工 | 補強管理 |

同盟解除を通告した国は、相手から与えられていた権限をその場で失います。

## 国庫・金庫・維持費

金庫は国家Hubから自国の支配チャンクに設定します。**首都チャンクは金庫にできません。**
設定済み金庫の変更には既定1時間のクールダウンがあり、Siege中は変更できません。
金庫または首都は、捕虜の安全な帰還先などにも使われます。

維持費は既定**24時間周期**です。

| 項目 | 既定コスト |
|---|---:|
| 領土 | 8チャンクごとに1TC |
| 拠点コア | 数に応じて逓増（1基8、2基24、3基48、4基80TC） |
| 車両コア | 1基あたり6TC |

未払い時は1時間ごとに再決済されます。放置すると段階的に弱くなります。

| 未払い期間 | 何が起きるか |
|---|---|
| 24時間未満 | 猶予状態。ペナルティなし |
| 24時間以上 | 補強・コアが受けるSiegeダメージが**2倍** |
| 72時間以上 | 補強保護・Bastion・コア回復が**停止**。実効領土半径が50%へ縮小 |

停止段階でもコア中心チャンクは残り、コア設置予約範囲そのものは変わりません。

車両コアにも維持費が掛かります。仕組みは[車両コア](../../reference/vehicle-core/)にまとめました。

## 留守のあいだ

### オフライン防御

防衛国の**最後のメンバーがログアウトして20分**経つと、補強とコアが受けるダメージは既定で3分の1になります。

効くかどうかは、そのコアで**ローリングSiegeが始まった時点**で決まります。オンラインで防衛中に始まったSiegeを、
**途中で全員ログアウトして有利に切り替えることはできません。** 日をまたいだSiegeは、その日の最初の有効打で決め直します。
陥落後フェーズでもオフライン防御は働きません。

[車両](../../reference/vehicle-core/#車両の保護)にも、自国の領土内に停めている間は同じオフライン防御が掛かります。

### 長期不在

最後の活動からの実時間に応じて、保護が段階的に弱くなります。

| 不在期間 | 受けるダメージ |
|---|---:|
| 7日未満 | ×1 |
| 7〜14日 | ×4/3 |
| 14〜21日 | ×2 |
| 21〜30日 | ×4 |
| 30日以上 | 補強保護そのものが停止 |

国家メンバーが活動を再開すれば状態は更新されます。
**維持費未払いの2倍ダメージなど、別の弱体化と重なることがあります。**
