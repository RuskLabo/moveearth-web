title: 拠点を作る

拠点の中心は**領土コア**です。コアが守られている限り土地は自分のもので、
コアが露出すれば戦争の標的になります。

守りの本体は「厚さ」ではなく**閉鎖**です。まず塞ぐ、次に厚くする、最後に払い続ける、の順で読んでください。

## 領土コア

領土は国家のコアを中心に成立します。

| コア | 既定最大HP | 落とされたら |
|---|---:|---|
| 首都コア | 2,000 | 完全陥落後も中心チャンクを再建領域として保持する |
| 拠点コア | 1,000 | 国家攻撃者なら占領される。無所属攻撃者や競合時は中立化 |
| 車両コア | 600 | Sable移動体の所有・補強・HP・維持費を管理する |

コアは**補強された閉鎖構造の中に置いて初めて**防御力を発揮します。
厚い壁に埋めるだけでは足りません。ドア、床、天井、整備経路まで含めて閉鎖してください。

## 漏出している状態

囲いに1ブロックでも穴があると、コアは `EXPOSED` へ移り、**コアへ直接ダメージが通ります。**
補強の厚さは関係ありません。

:::caution[天井と床も閉鎖の一部です]
横を固めても、上から掘られれば同じことです。閉鎖判定は**立体**で見ます。
:::

### 何が遮蔽として数えられるか

| 数えられる | 数えられない |
|---|---|
| 有効な補強が付いた、十分な衝突判定を持つブロック | 未補強のブロック |
| 補強されたドア（**開いていても**遮蔽として扱われます） | 破壊された補強 |
| 補強されたトラップドア | 停止中の補強（維持費の長期未払いなど） |

溶接機のオーバーレイは補強状態だけでなく、**漏出の原因になりうる未補強部分**を見つけるのにも使えます。
`EXPOSED` になっているのに原因が分からないときは、まずこれで一周してください。

## 補強する

溶接機をメインハンドに、材料をオフハンドに持って対象を右クリックします。

| 材料 | 補強最大HP |
|---|---:|
| 丸石 | 32 |
| 銅インゴット | 64 |
| 鉄インゴット | 128 |
| 金インゴット | 192 |
| ダイヤモンド | 320 |

- 修理材1個あたり、**最大HPの25パーセント**が戻ります
- 新規補強は即時完成しません。**30秒の起動待ち**のあと、**60秒かけて**HPが増えます
- 施工・起動中は見た目、オーバーレイ、進捗表示、周囲に聞こえる作業音で確認できます
- Jade導入環境では補強の有無・状態・HPを見られます
- 溶接機の範囲施工は 1×1 / 3×3 / 5×5 で、選択範囲の外周が緑色で表示されます

:::caution[被弾した場所はすぐに直せません]
有効ダメージを受けた位置は既定**60秒の修復待ち**になります。再被弾で延長され、
**補強を壊して同じ位置にブロックを置き直しても回避できません。**
待機が明けてから修理でき、新規補強ならさらに通常の30秒起動待ちとHP増加が要ります。
建設中の補強が被弾すると自動のHP増加は止まり、以後は手動修理になります。
:::

## Bastion領土保護

他国領土では、権限を持たないプレイヤーの次の行動が抑止されます。

- 通常ブロック・液体の設置
- ボート・トロッコなどの設置
- エンダーパールによる侵入

敵領土でも降車・降下はできます。降下兵にも設置とパールの制限は掛かりますが、
**C4と露出コアへの工作は通常どおり**使えます。降車を理由にした強制帰還はありません。

自国・同盟国であっても `BASTION_ACCESS` が必要です。管理者・クリエイティブ・スペクテイターは対象外、
攻城用C4を敵の補強面へ取り付ける正規操作は例外として許可されます。

:::danger[維持費を止めるとBastionも止まります]
維持費が長期未払いでBastionが停止している領土では、この保護は働きません。
:::

## 国庫・金庫・維持費

金庫は国家Hubから自国の支配チャンクに設定します。**首都チャンクは金庫にできません。**
設定済み金庫の変更には既定1開放時間のクールダウンがあり、Siege中は変更できません。
金庫または首都は、捕虜の安全な帰還先などにも使われます。

維持費は既定**24時間周期**です。

| 項目 | 既定コスト |
|---|---:|
| 領土 | 8チャンクごとに金貨1 |
| 拠点コア | 1基あたり金貨8 |
| 車両コア | 1基あたり金貨6 |

未払い時は1時間ごとに再決済されます。放置すると段階的に弱くなります。

| 未払い期間 | 何が起きるか |
|---|---|
| 24時間未満 | 猶予状態。ペナルティなし |
| 24時間以上 | 補強・コアが受けるSiegeダメージが**2倍** |
| 72時間以上 | 補強保護・Bastion・コア回復が**停止**。実効領土半径が50%へ縮小 |

停止段階でもコア中心チャンクは残り、コア設置予約範囲そのものは変わりません。

## 留守のあいだ

### オフライン防御

防衛国の**最後のメンバーがログアウトして20分**経つと、補強とコアが受けるダメージは既定で3分の1になります。

ただし、オンライン防衛中に始まったローリングSiegeを、**途中で全員ログアウトして有利に切り替えることはできません。**
陥落後フェーズでもオフライン防御は働きません。

### 長期不在

最後の活動からの実時間に応じて、保護が段階的に弱くなります。

| 不在期間 | 受けるダメージ |
|---|---:|
| 7日未満 | ×1 |
| 7〜14日 | ×4/3 |
| 14〜21日 | ×2 |
| 21〜30日 | ×4 |
| 30日以上 | 補強保護そのものが停止 |

国家メンバーが活動を再開すれば状態は更新されます。
**維持費未払いの2倍ダメージなど、別の弱体化と重なることがあります。**

## 車両コアと移動補強

車両コアはSable移動体に国家所有・600HP・補強情報・維持費を持たせます。
スイベルやヒンジを含む組立・移動でも、接続された車体の補強と被弾情報を**車両ID単位**で追跡します。

車体の補強壁は領土補強と同じようにCBC・Warnauticsの攻撃を受け、残っている装甲の背後にある車両コアを守ります。

- 自国車両コアにつながった移動体の対象収納は、**領土外でも**自国メンバーが使用・設置できます。他国車両や、コアのない切り離された部品にこの例外はありません
- 車両HPが0になると、撃破した正規攻撃勢力へ**30開放分の貨物回収権**が付き、撃破は戦史へ一度だけ記録されます
- 捕虜を徒歩護送中、拘束具を持って自国の稼働車両コアをスニーク右クリックすると1人を積載できます。同じ操作で降ろせます。拘束期限は延長されず、車両が撃破されると捕虜はその場で救出されます

車両は、固定砲では取りにくい射線へ重砲を移動し、破口とコアを狙うための戦力です。
重砲の射撃準備時間システムは実装されていません。

### 車両の修理

自国車両コアの**6ブロック以内**で、メインハンドに溶接機、オフハンドに鉄インゴットを持ってスニーク右クリックします。
`MANAGE_REINFORCEMENT` 権限と、有効な維持費状態が必要です。
