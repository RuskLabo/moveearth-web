---
title: 市場と物資輸送
description: 売り注文・買い注文と市場ステーションでの現地受け渡し。
---

`/market` で商品・価格・注文・受取待ちを確認します。
[地方ごとの資源偏在](../resources/)によって自国で採れない戦略資源や特産品を調達するための仕組みです。
**画面はどこでも開けますが、アイテムは遠隔転送されません。**
TCの決済と、現物を受け取る操作は別です。

## ステーションを用意する

市場ステーションは、領土管理権限を持つメンバーが **自国の稼働領土に1国1台** 設置します。
予約中・停止中の土地、権限不足の場合や、2台目以降の設置では登録できません。
普通のチェストではなく、注文の預託品と受取待ちを管理する受け渡し地点です。
クラフトは真鍮ケーシング4、鉄ブロック2、チェスト2、レッドストーンコンパレーター1です。

## 売り注文の商品を買う

1. 売り手は自国ステーションから**8ブロック以内**で、商品をメインハンドに持ちます。
2. 数量と「1個あたりの価格（TC）」を指定し、売り注文を作成します。商品は預託され、手元から減ります。
3. 買い手は `/market` で商品と価格、**受取先ステーション**を確認して購入します。
4. TCの支払い後、商品は受取待ちになります。購入した場所には出現しません。
5. 売り手のステーションまで行き、8ブロック以内で「受取」を実行します。

## 買い注文へ商品を納める

1. 買い手は自国ステーションを受取先として、欲しい商品をメインハンドに持ち、買い注文を作ります。
2. 注文総額のTCを先に預けます。商品見本を持つことと、納品することは別です。
3. 売りたい人は商品を持って、**買い手のステーションまで輸送**します。
4. ステーションから8ブロック以内で納品すると、商品を渡し、TCを受け取ります。見本と**完全に同じもの**（耐久値・エンチャントも含む）しか納品できません。
5. 買い手は自国ステーションで納品された現物を回収します。

| 注文 | 運ぶ人 | 現物の受け渡し先 |
|---|---|---|
| 売り注文 | 購入した人が取りに行く | 売り手のステーション |
| 買い注文 | 納品する人が運んで行く | 買い手のステーション |

自分の注文には、購入も納品もできません。

## 上限

| 項目 | 上限 |
|---|---|
| 1人が同時に出せる注文 | 16件 |
| 1注文の数量 | 4,096個 |
| 単価 | 1,000,000TC |
| 1台のステーションが預かる量（売り注文の在庫＋受取待ち） | 16,384個 |
| 注文の期限 | 出してから実時間で7日 |

## 目的地・取消・受取

- 注文の目的地設定を使うと、ステーション名・距離・アイコンのウェイポイントが表示されます。解除も市場画面から行えます。
- 商品名だけでなく、銃種・付与情報などの商品詳細、数量、単価、総額を確認してください。
- 一覧には自分の注文が必ず先頭に出ます。他人の注文は売り・買いそれぞれ最大48件です。各商品の一番安い（買いは高い）注文から、商品を順に巡って1件ずつ選ばれます。目当ての商品は検索で絞り込んでください。検索はサーバー側で行われ、日本語の商品名でも探せます。
- 未成立分の注文は取消できます。買い注文の未使用預託金は返金され、売り注文の残品は**元のステーションで受取待ち**になります。
- 期限切れは取消と同じ扱いです。どちらも、商品を今いる場所へ送る機能ではありません。
- 受取は1回につき1スタックです。インベントリが満杯なら空きを作り、受取待ちの残数を確認してください。
- 自国が土地を失っても、ステーションが残っていれば受取はできます。止まるのは新しい取引だけです。
- 市場の緊急停止中も取消と受取は可能です。新規注文・購入・納品は停止します。

:::caution[ステーションを撤去する前に]
撤去・破壊されると、そのステーションの注文はすべて取り消されます。買い注文の未使用預託金は返金され、売り注文の残品と受取待ちは**同じ場所の残骸**に移ります。
残骸からは、各持ち主（と略奪権を持つ攻撃側）がその場で回収します。置き直しても物資は新しいステーションへ移りません。
:::

新規アカウントには送金等と合算した支出制限があります。[所持金・送金](../balance/)も確認してください。
