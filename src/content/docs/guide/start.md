MoveEarthは、プレイヤーが国を作り、土地を取り、争い、滅び、立て直す場所です。
このガイドは「拠点を作る」「戦争をする」の2本を軸にしています。どちらも**国家に所属しているか、
自分で作っているか**を前提にしているので、まずそこから始めてください。

## このwikiの歩き方

| あなたの状況 | 読むもの |
|---|---|
| まだ国に入っていない | このページ |
| 拠点を建てたい、守りを固めたい | [拠点を作る](../base/) |
| 攻めたい、攻められている | [戦争をする](../siege/) |
| 国が滅んだ | [戦争をする](../siege/) の「負けたあと」 |

個別のシステム（TPA、Jobs、初期装備など）は**リファレンス**にまとめてあります。
ここは「何をするか」、リファレンスは「これは何か」です。

## サーバー開放時間

専用サーバーは **JST 18:00〜00:00** を標準の開放窓としています。
Siegeのタイマーなど、時間で進む仕組みは原則としてこの時間内だけ進みます。
閉鎖時間をまたいでも残り時間を実時間で消費しません。
