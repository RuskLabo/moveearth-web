MoveEarthは、プレイヤーが国を作り、土地を取り、争い、滅び、立て直す場所です。
このガイドは「[拠点を作る](../base/)」「[戦争をする](../siege/)」の2本を軸にしていますが、
**どちらも国家に所属していることが前提**です。まずそこから始めてください。

## 初回参加の流れ

初めてログインすると「はじめ方を選ぶ」画面が開きます。どちらを選んでも、あとから建国・加入できます。

| 選択 | 始まり方 |
|---|---|
| 国を作る | 荒野のランダムな地点から始まる。拠点にしたい土地を探し、国家ハブで国家を作成する |
| 国に入る | 加入したい国家を選んで申請する。承認されると、その国家の近くから始まる |

- 承認を待たずに「申請したまま荒野で開始」もできます。プレイ中に承認されると、**今いる場所のまま**国家に加入します。
- 加入申請は**一度に1件だけ**です。申請・取消の直後は15秒ほど次の申請ができません。
- 申請はあとから国家ハブでも出せます。国家がまだ無いときは荒野から始めます。

ゲーム内チュートリアルは画面右側の目標を追います。`/tutorial skip` でスキップ、`/tutorial restart` で最初から表示し直せます（達成済みの手順は自動で進みます）。
バニラの進捗画面（`L`）も、この世界の遊び方と工業の節目を案内します。

## 最初の壁

:::danger[国家に入るまでチェストが使えません]
国家に所属していないプレイヤーは、**保管設備を設置することも、開けることも、壊すこともできません。**
チェスト、トラップチェスト、樽、シュルカーボックス、ホッパー、ドロッパー、ディスペンサー、飾り壺、模様入りの本棚、バンドル、チェスト付き・ホッパー付きトロッコ、チェスト付きボート、Createのアイテム金庫・ツールボックスが対象です。

これは不具合ではなく意図された制限です。**国家に入るか、自分で作るか**で解禁されます。
:::

解禁されるのは、加入申請が承認されたとき、招待を受けて参加したとき、または**国家の作成と首都コアの登録が両方成功した**ときです。
申請を出しただけ、設立ウィザードの途中の段階では、まだ未所属として扱われます。

所属したあとも、保管設備を使える場所は決まっています。

| 場所 | 保管設備 |
|---|---|
| 自国の領土 | 使える |
| 自国のSable（乗り物・飛行船MOD）の車両の上 | 使える |
| 同盟国の領土 | 相手国が外交画面の権限で「倉庫」を許可したときだけ使える |
| 荒野・他国の領土 | 使えない（Siege中の[戦利品回収](../loot/)を除く） |

エンダーチェストは国家所属とは別の理由で、サーバー全体で禁止されており、使用・設置・クラフトができません。

## 国家ハブを開く

ほとんどの操作は**国家ハブ**から行います。開き方は2つです。

| 操作 | 既定 |
|---|---|
| 国家ハブを開く | **`N`** または `/nation` |
| 捕虜・護送画面 | `J` |
| 補強オーバーレイ切替 | 溶接機を持って `G` |
| 補強の範囲変更 | 溶接機を持ってマウスホイール（1×1 / 3×3 / 5×5） |
| 領土プレビューを閉じる | `V` |
| 地図上の領土表示 | **初期状態では未割当。** キー設定から割り当ててください |
| 復興・戦史 | 国家ハブ内の「復興・派遣」ボタン |

キーはMinecraftのキー設定から変更できます。画面内の案内は固定文字ではなく、
**現在割り当てられているキー**を表示します。

## どちらを選ぶか

| | 既存の国家に入る | 自分で国を作る |
|---|---|---|
| 必要なもの | 受け入れてくれる国 | 設立地点、そして拠点を守り続ける覚悟 |
| 向いている人 | まず遊び方を知りたい | 自分の土地と方針を持ちたい |
| 責任 | 与えられた権限の範囲 | 維持費、防衛、メンバー |

**迷うなら既存の国家に入ることを勧めます。** 拠点の維持費は国家が払うもので、
一人で背負うと[留守のあいだ](../base/#留守のあいだ)の弱体化がそのまま効きます。

## 国を作る

国家の設立は、名前を決める操作ではなく**設立地点・首都コア・初期領土を同時に確定する操作**です。

1. **`N`** で国家ハブを開き、国家作成へ進む
2. 国家作成画面で**名称とTAG**を入力する。名称は3〜32文字、TAGは**半角英数字2〜5文字**
3. 「設立地点を選択」でワールド表示へ移る
4. 照準した地表に、首都コアと**半径1チャンク（3×3チャンク）の予約領土**がプレビュー表示される
5. 緑／赤の境界と競合理由を見て、地面を**右クリックで確定**する（左クリックで戻る）
6. サーバーが国家・首都コア・予約領土をまとめて作成する
7. 首都コアの画面と**密閉診断**が開くので、そのまま外殻の施工へ進む

設立地点は、自分から**10ブロック以内**で、目で見えている（間に遮るものがない）地面の上でなければなりません。
水や溶岩の中、上が塞がっている場所には置けません。

首都コアはアイテムを消費せず、サーバーが設置します。最大HPは満タンの状態で始まります。

:::caution[置いただけでは領土になりません]
首都コアは設置直後「設定中」の状態で、**密閉判定に合格して初めて有効な領土になります。**
予約領土は先に確保されますが、**設定中の予約が持つのは開放時間で1時間だけ**です。それを過ぎると他国が割り込めます。
過ぎても、他国に取られていない範囲は補強を続けられます。残り時間はコアの画面で確認できます。

そのまま[拠点を作る](../base/)へ進んで、外殻を閉じてください。
:::

設立地点には制約があります。**Sable（乗り物・飛行船MOD）の移動体やCreateのコントラプション上には首都を作れません。**
座標が動いてしまい、固定の領土と噛み合わないためです。

## 国家のしくみ

### 所有は個人ではなく国家

領土コアや補強などの所有権は、**原則として個人ではなく国家に帰属します。**
あなたが置いた補強も、国家のものです。

例外は[プレイヤー検知ブロック](../player-detector/)で、置いた人の個人所有です。稼働費も所有者個人のTCから払います。

### 役職と権限

権限は役職ごとに割り当てられます。役職名ごとに権限があらかじめ固定されているわけではなく、
国家ごとに役職の権限構成を自由に設定できます。主な権限は次のとおりです。

権限の名前は、国家ハブの役職画面に出るものと同じです。

| 権限 | 主な用途 |
|---|---|
| 補強管理 | 補強の施工・修理、[車両の修理](../../reference/vehicle-core/) |
| 領土管理 | コア・領土・金庫の管理 |
| 国庫管理 | 国庫 |
| Siege管理 | Siegeの撤退・降伏 |
| 外交管理 | 講和の提案・承認・拒否、外交操作 |
| 捕虜管理・正式解放 | 収監中の捕虜の正式解放 |
| 領土・同盟領土アクセス | 自国・同盟国領土内での[Bastion](../base/#bastion領土保護)制限対象の操作 |

ほかにメンバー管理（招待・追放）、役職・権限管理、通知・Discord連携管理があります。

**何かができないときは、まず自分の役職にその権限があるか確認してください。**

:::note[戦争中はロックされる操作があります]
Siege中や陥落処理中は、対象コアの撤去・半径変更など戦況を無効化する操作がロックされます。
国家からの自主脱退、国家の移譲・解散も、戦争や捕虜関係が残っているあいだは制限されます。
:::

### 他国との関係

| 関係 | 成立のしかた |
|---|---|
| 同盟 | 双方の合意による相互関係 |
| 中立 | 既定 |
| 敵対 | 一方的に指定できる |

ネームタグには国家タグが `[TAG] PlayerName` の形で付き、**見ている人から見た関係**で色が変わります。
自国はシアン、同盟は緑、敵対は赤、中立は灰色です。

領土の取り合いは通常のPvPではなく、明示的な[Siege](../siege/)として扱われます。

敵対を宣言していない国家（どちらからも敵対が無く、戦争中でもない国家）の補強やコアを攻撃すると、最初の一撃は止められ、**戦争開始の確認画面**が出ます。
確認すると、その国家への攻撃が10分間有効になります（途中でログアウトすると切れます）。
大砲や爆弾など**人の手を介さない攻撃**には確認の機会が無いため、先に敵対を宣言しておく必要があります。

## 国家を抜ける・追い出されるとき

国家を離れたあとの待ち時間は、すべて**開放時間で4時間**です。

| きっかけ | 他の国家への加入 | 建国 |
|---|---|---|
| 自分で脱退した | 4時間できない | 4時間できない |
| 追放された | すぐできる | 4時間できない |
| 国主が解散した（国主本人） | 4時間できない | 4時間できない |
| 国主が解散した（ほかのメンバー） | すぐできる | すぐできる |

脱退・追放のあとも、待ち時間のあいだは元の国家の同盟相手・停戦相手を攻撃できません。
同盟（解消予告中を含む）や講和の停戦がある国家は解散できません。

## プレイできる時間

プレイできる時間は、毎日 **19:00〜23:00 JST** です。
Siegeや捕虜などのゲーム内タイマーは、原則としてこの時間内だけ進みます。
時間外は、サーバーが動いていても残り時間は減りません。維持費の請求周期など、別の数え方をするものは各画面で確認してください。

閉鎖前には22:30・22:50・22:55・22:59に予告が出て、23:00に全員が切断されます。この切断は[戦闘中のログアウト](../combat/)扱いになりません。
閉鎖中は昼夜と天候が止まります。そのため季節の進みも、開放時間の分だけになります。
