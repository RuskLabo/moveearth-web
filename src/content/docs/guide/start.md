MoveEarthは、プレイヤーが国を作り、土地を取り、争い、滅び、立て直す場所です。
このガイドは「[拠点を作る](../base/)」「[戦争をする](../siege/)」の2本を軸にしていますが、
**どちらも国家に所属していることが前提**です。まずそこから始めてください。

## 最初の壁

:::danger[国家に入るまでチェストが使えません]
国家に所属していないプレイヤーは、**保管設備を設置することも、開けることもできません。**
チェスト、樽、シュルカーボックス、ホッパー、チェスト付きトロッコなどが対象です。

これは不具合ではなく意図された制限です。**国家に入るか、自分で作るか**で解禁されます。
:::

解禁されるのは、**国家の作成と首都コアの登録が両方成功した時点**です。
加入申請を出しただけ、招待を受けただけ、設立ウィザードの途中の段階では、まだ未所属として扱われます。

| できること | できないこと |
|---|---|
| 既にあるコンテナを**壊して中身を回収する** | 新しく設置する、開ける |
| 所持品（インベントリ）の利用と、既に持っているアイテムの回収 | シュルカーボックスなど可搬ストレージの使用 |

エンダーチェストは国家所属とは別の理由で、サーバー全体で禁止されており、使用・設置・クラフトができません。

## 国家ハブを開く

ほとんどの操作は**国家ハブ**から行います。開き方は2つです。

| 操作 | 既定 |
|---|---|
| 国家ハブを開く | **`N`** または `/nation` |
| 捕虜・護送画面 | `J` |
| 補強オーバーレイ切替 | 溶接機を持って `G` |
| 補強の範囲変更 | 溶接機を持ってマウスホイール（1×1 / 3×3 / 5×5） |
| 領土プレビューを閉じる | `V` |
| 地図上の領土表示 | **初期状態では未割当。** キー設定から割り当ててください |
| 復興・派遣・戦史 | 国家ハブ内の「復興・派遣」ボタン |

キーはMinecraftのキー設定から変更できます。画面内の案内は固定文字ではなく、
**現在割り当てられているキー**を表示します。

## どちらを選ぶか

| | 既存の国家に入る | 自分で国を作る |
|---|---|---|
| 必要なもの | 受け入れてくれる国 | 設立地点、そして拠点を守り続ける覚悟 |
| 向いている人 | まず遊び方を知りたい | 自分の土地と方針を持ちたい |
| 責任 | 与えられた権限の範囲 | 維持費、防衛、メンバー |

**迷うなら既存の国家に入ることを勧めます。** 拠点の維持費は国家が払うもので、
一人で背負うと[留守のあいだ](../base/#留守のあいだ)の弱体化がそのまま効きます。

## 国を作る

国家の設立は、名前を決める操作ではなく**設立地点・首都コア・初期領土を同時に確定する操作**です。

1. **`N`** で国家ハブを開き、国家作成へ進む
2. 国家作成画面で**名称とTAG**を入力する
3. 「設立地点を選択」でワールド表示へ移る
4. 照準した地表に、首都コアと**半径1チャンクの予約領土**がプレビュー表示される
5. 緑／赤の境界と競合理由を見て決定する
6. サーバーが国家・首都コア・予約領土をまとめて作成する
7. 首都コアの画面と**閉鎖診断**が開くので、そのまま外殻の施工へ進む

首都コアはアイテムを消費せず、サーバーが設置します。最大HPは満タンの状態で始まります。

:::caution[置いただけでは領土になりません]
首都コアは設置直後 `CONFIGURING` 状態で、**閉鎖判定に合格して初めて有効な領土になります。**
予約領土だけは先に確保されるので、他国に割り込まれる心配はありません。

そのまま[拠点を作る](../base/)へ進んで、外殻を閉じてください。
:::

設立地点には制約があります。**Sable（乗り物・飛行船MOD）の移動体やCreateのコントラプション上には首都を作れません。**
座標が動いてしまい、固定の領土と噛み合わないためです。

## 国家のしくみ

### 所有は個人ではなく国家

領土コア、補強、プレイヤー検知ブロックなどの所有権は、**原則として個人ではなく国家に帰属します。**
あなたが置いた補強も、国家のものです。

### 役職と権限

権限は役職ごとに割り当てられます。役職名ごとに権限があらかじめ固定されているわけではなく、
国家ごとに役職の権限構成を自由に設定できます。主な権限は次のとおりです。

権限の名前は、国家ハブの役職画面に出るものと同じです。

| 権限 | 主な用途 |
|---|---|
| 補強管理 | 補強の施工・修理、[車両の修理](../../reference/vehicle-core/) |
| 領土管理 | コア・領土・金庫の管理 |
| 国庫管理 | 国庫、派遣契約の資金確保 |
| Siege管理 | Siegeの撤退・降伏、派遣契約の雇用側承認 |
| 外交管理 | 講和の提案・承認・拒否、外交操作 |
| 派遣契約の承認・管理 | 派遣元国家としての契約承認・管理 |
| 捕虜管理・正式解放 | 収監中の捕虜の正式解放 |
| 領土・同盟領土アクセス | 自国・同盟国領土内での[Bastion](../base/#bastion領土保護)制限対象の操作 |

ほかにメンバーの招待・追放、役職の編集、プレイヤー検知ブロックの設定などがあります。

**何かができないときは、まず自分の役職にその権限があるか確認してください。**

:::note[戦争中はロックされる操作があります]
Siege中や陥落処理中は、対象コアの撤去・半径変更など戦況を無効化する操作がロックされます。
国家からの自主脱退、国家の移譲・解散も、戦争や捕虜関係が残っているあいだは制限されます。
:::

### 他国との関係

| 関係 | 成立のしかた |
|---|---|
| 同盟 | 双方の合意による相互関係 |
| 中立 | 既定 |
| 敵対 | 一方的に指定できる |

ネームタグには国家タグが `[TAG] PlayerName` の形で付き、**見ている人から見た関係**で色が変わります。
自国はシアン、同盟は緑、敵対は赤、中立は灰色です。

領土の取り合いは通常のPvPではなく、明示的な[Siege](../siege/)として扱われます。

## サーバー開放時間

専用サーバーは **JST 19:00〜23:00** を標準の開放時間（稼働時間帯）としています。
Siegeのタイマーなど時間で進む仕組みは、原則としてこの時間内だけ進みます。
閉鎖時間（サーバー停止中）は残り時間が減りません（実時間は経過しません）。
