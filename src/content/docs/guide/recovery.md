title: 立て直す
description: 首都を落とされたあと。何が残り、何から手を付けるか。
---

**首都を完全に落とされても、国は消えません。** 敗戦国には**復興エピソード**が作られます。
このページは、そこから戻るまでの話です。

:::tip[滅んだら終わり、にしないための仕組みです]
首都陥落で国家解散しか選択肢がないと、敗戦したプレイヤーがサーバーを離脱してしまいます。
復興エピソードは「立て直して報復に行く」ほうを選べるようにするために用意されています。
:::

## 落とされた直後に残るもの

首都コアが30分の陥落フェーズを守り切られると、次の状態になります。

| | |
|---|---|
| 国家 | **消えません。** 所有国も変わりません |
| 領土 | **中心チャンクだけ**が再建領域として残ります |
| 首都コア | **最大HPの25%**。再建状態から再開 |
| 再攻撃の猶予 | 既定**6開放時間**。このあいだは攻められません |

拠点コアを落とされた場合は違います。そちらは相手に占領されるか、割り当てられなければ中立化します。
**復興エピソードが始まるのは首都を落とされたときだけ**です。

:::note[「開放時間」は実時間ではありません]
サーバーの開放時間は JST 19:00〜23:00 の**1日4時間**です。
「6開放時間」はおおよそ**1日半**、「28開放時間」は**1週間**、「56開放時間」は**2週間**にあたります。
:::

## 最初にやること

**閉じ直してください。** 攻め返す算段より先です。

復興の進捗のうち最大の一塊が「**首都を再封鎖し、開放時間内に10分間維持する**」だからです。
閉鎖のやり方は[拠点を作る](../base/#閉鎖が成立している状態)と同じで、コアを隙間なく囲うだけです。

再攻撃の猶予があるうちに閉じてしまえば、そのまま10分間の維持に入れます。

## 復興の進捗

国家ハブ（`N`）の「復興・派遣」画面から、進捗・残り資格時間・戦史を見られます。

| やること | 進捗 |
|---|---:|
| 復興が始まった時点で | 30% |
| 首都を**再封鎖して開放時間内に10分間維持**する | +30% |
| 開戦時の**防壁HP評価まで復旧**する | +20% |
| **維持費を実際に再決済**する | +20% |

| | 既定 |
|---|---:|
| 支援資格期間 | 28開放時間（約1週間分） |
| 同じ種類の復興を再利用するクールダウン | 56開放時間（約2週間分） |

:::caution[復興基金は既定で無効です]
この進捗は復興支援を受ける資格に使われますが、**基金そのものが既定設定では無効**です。
台帳・上限・審査の仕組みは実装済みですが、有効化されていない限り
**敗戦しただけで自動的に金貨が配られることはありません。**

有効かどうかは運営に確認してください。
:::

## 防壁の復旧は「量」ではなく「質」

進捗の3つ目、**防壁HP評価の復旧**だけは仕組みが特殊です。ここを誤解すると無駄な作業をします。

開戦時、最初の有効な攻撃を受けた時点で、**そのときの補強の最大HPと個数**が記録されます。
復旧判定は、**同じ個数の上限内で、強い補強から順に**実HPを合計します。

| | |
|---|---|
| 記録されるタイミング | 開戦時、最初の有効な攻撃を受けた瞬間 |
| 記録される内容 | 補強の最大HPと、その個数 |
| 個数の上限 | 既定4,096個 |
| 復旧時の数え方 | 同じ個数まで、**強い順**に実HPを合計 |

### 例

開戦時にダイヤ補強が**2個**（320 × 2 = 640HP）だったとします。

| 復旧のしかた | 評価 |
|---|---:|
| ダイヤ2個を置き直す | 640HP ✅ |
| **丸石を3,000個**置く | 強い順に2個まで＝**64HP** ❌ |
| ダイヤ1個＋鉄1個 | 320 + 128 = 448HP |

**個数が上限なので、安い材料をいくら積んでも戻りません。** 元と同じ質のものを、同じ数だけ戻す必要があります。

位置は変えられます。元の領域内で自国が補強できる場所なら、配置は自由です。
ただし**他国の補強は評価されません。**

:::note[見に行かないと反映されません]
復旧の確認には対象チャンクが読み込まれている必要があります。
**評価のための強制ロードは行われません。** 直したら自分で見に行ってください。
:::

## 報復へ戻る

復興はやり直しの猶予ですが、**そこに留まる義務はありません。**

- **再建保護を自ら放棄して攻勢へ戻れます。** 守りを捨てて報復に向かう選択です
- 落とした相手を**宿敵として表示**できます
- 戦史の公開範囲（公開／自国のみ）を選べます

守りを固めてから出るか、保護を捨てて即座に報復するかは、状況次第です。
**猶予のあいだは攻められない**ので、時間を守りに使うか、準備に使うかという判断になります。
